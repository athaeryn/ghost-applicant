# Roles

Add one file per employer here: `<company>-<role>.md`.

Frontmatter template:

```markdown
---
company: ACME
role: Senior Engineer
start: 2020-01
end: 2023-06
location: Remote
---
```

## Suggested sections (facts, not polish)

## Summary

One or two factual sentences about the scope of the role.

## Responsibilities

Bullets describing what you were actually accountable for.

## Key accomplishments

Real, verifiable outcomes. Use concrete metrics only if true (percentages,
counts, scope, team size, budgets, users).

## Tools & technologies

What you actually used and why.
